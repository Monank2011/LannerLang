# Stable VS Code Icon Support

This folder contains the official Stable editor branding for `.st` source files.

The extension contributes the `stable` language identifier for `.st` files and uses the Stable logo as the language icon. It also provides a `Stable File Icons` theme that maps `.st` directly to the same logo.

## Use

Open this folder as a VS Code extension during development, or package it as a VSIX for installation.

After installing, select `Preferences: File Icon Theme` and choose `Stable File Icons` when the active icon theme does not show the language-contributed Stable logo.
