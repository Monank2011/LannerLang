# LannerLang 3.0.0 Source Archive

This archive contains the source-only LannerLang 3.0.0 tree.

- Language source files use the `.lan` extension.
- The compiler executable is `lanner`.
- Build with CMake; see `README.md` and `docs/INSTALL.md`.
- Build outputs, Git metadata, release archives, caches, and binary artwork are intentionally omitted.
- The project was created and developed by Monank Gohil, who began developing it at age 15.

Suggested starting point for chess-engine work: `examples/chess_engine_kernel_audit.lan`, `examples/bitboard.lan`, and `docs/ENGINE_RUNTIME.md`.
New in 3.0.0: `examples/compound_assign.lan`, `examples/range_loops.lan`, `examples/ergonomics_v3.lan`.
